## 🖨️ How to Save as PDF

1. **Open** the HTML file in your browser (Chrome recommended)
2. **Click** the purple `🖨️ Save as PDF` button at the bottom-right of the page
3. In the print dialog:
   - Set **Destination** → `Save as PDF`
   - Set **Paper size** → `A4`
   - Set **Margins** → `Default`
   - Enable **Background graphics** ✅ (important for colors!)
4. Click **Save**

> [!TIP]
> In Chrome: `Ctrl+P` → More settings → enable **Background graphics** to preserve all colors and gradients.
